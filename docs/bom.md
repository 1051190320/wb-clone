# 物料清单（BOM）与外壳

## 方案 A：推荐（≈ ¥25–40，圆屏最还原）

| 部件 | 型号/规格 | 参考价 | 数量 | 备注 |
|---|---|---|---|---|
| 开发板 | **ESP32-C3 SuperMini** | ¥10–15 | 1 | RISC-V 单核 160MHz，USB-C 原生 CDC（插线即用，免 CH340） |
| 屏幕 | **1.28" GC9A01 圆屏**（240×240 SPI） | ¥15–25 | 1 | 圆形 IPS，驱动与固件 `boards/esp32c3_gc9a01/` 已配好 |
| 杜邦线 | 母对母 7 根（或焊接） | ¥2 | 1 套 | 见下表接线； SuperMini 排针间距 2.54mm |
| 外壳 | 3D 打印（见下文尺寸） | ¥10–20 耗材 | 1 | 双色或后期上色 |

> 这是「屏 + 板」分离方案：7 根线即可点亮，总价最低；圆屏 240×240 最接近原版比例，固件默认环境 `esp32c3_gc9a01`。
> 换板只需在 `firmware/boards/<新板型>/` 放一份 `tft_setup.h` + `board.h`，platformio.ini 加一个 env，**不动一行 UI 代码**。

| 部件 | 型号/规格 | 参考价 | 数量 | 备注 |
|---|---|---|---|---|

## 方案 C：零焊接演示版（≈ ¥0）

用 **网页模拟器**（`simulator/index.html`）+ Bridge `--dry-run` 模式，在电脑上完整演示协议与交互，不花一分钱。

## 方案 A 接线（ESP32-C3 SuperMini → GC9A01）

| 屏幕丝印 | ESP32-C3 GPIO | 说明 |
|---|---|---|
| VCC | 3V3 | 3.3V 供电（C3 无 5V 耐接待定，勿接 5V） |
| GND | GND | 共地 |
| SCL (SCLK) | GPIO4 | SPI 时钟 |
| SDA (MOSI) | GPIO3 | SPI 数据（C3 无硬件 MISO 用途，屏无 MISO） |
| CS | GPIO1 | 片选 |
| DC | GPIO10 | 数据/命令 |
| RST | GPIO0 | 复位（C3 的 strapping 脚，上电即释放即可正常启动） |
| BL | 未接 | 圆屏模块背光多为恒亮；`board.h` 中 `WB_BL_PIN -1` |

> 引脚定义集中在 `firmware/boards/esp32c3_gc9a01/tft_setup.h`（TFT_eSPI 外部配置）与 `board.h`（尺寸/旋转/背光），改线只动这两个文件。

## 方案 B 引脚（CYD 板载，无需自己接）

屏幕 SPI 固定在板上，仅作了解：

| 功能 | ESP32 GPIO |
|---|---|
| TFT_MOSI | 13 |
| TFT_SCLK | 14 |
| TFT_CS | 15 |
| TFT_DC | 2 |
| TFT_RST | -1（接 EN；个别批次为 GPIO4） |
| TFT_MISO | 12 |
| TFT_BL | 21 |
| USB | CH340 → UART0（GPIO1/3） |

## 3D 打印外壳

复刻原版标注的尺寸（单位 mm）：

| 部位 | 尺寸 |
|---|---|
| 正面面板（宽 × 高） | 52 × 107 |
| 机身深度（前后） | 70 |
| 底部占地（宽 × 深） | 50 × 70 |

方案 A（圆屏）组合尺寸：GC9A01 屏 PCB 直径约 40mm + ESP32-C3 SuperMini 22.5×18mm，可斜置/并排放进原版 52×107 面板内，前框开 **直径约 34mm 圆窗**（可见区约 32mm，建议量屏后留 0.3mm 间隙）。结构建议（分 3 件，避免拆屏）：

1. **前框**（薄荷绿）：开圆窗 + 顶部两个猫耳三角孔
2. **后盖**（米白）：开 USB 出线孔，4×M2 自攻螺丝柱（可贴屏 PCB 边缘或粘 SuperMini）
3. **猫爪装饰件**（薄荷绿）：屏幕下方贴装/卡装

打印参数：PLA、0.2mm 层高、2 道外墙、15% 填充。配色贴近原版：机身米白 `#F6F3EC` + 猫耳/猫爪薄荷绿 `#8FD0B5`。双色打印（AMS/IDEX）或拼接后上色均可。

## 电源与功耗

- 5V USB 供电，整机典型约 60–100mA、WiFi 发射峰值约 200mA（1W 级）
- 无电池、无触摸、无按键、无声音——与原版"四无"设计一致，纯显示终端
- 方案 A 圆屏背光常亮（BL 未接 = 恒亮）；方案 B CYD 背光 GPIO21，可改固件 `WB_BL_PIN` 加 PWM 呼吸灯
